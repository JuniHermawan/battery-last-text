One single-line last text from a phone battery to its charger (89 characters), written by a deterministic Python program for make.fun's "The Battery's Last Text to Its Charger" bounty: the battery waited all day at 1%, and now it is dying mid-text — the message itself cuts off mid-word, performing the death it describes. The turn pays off in the very last characters, and it stays funny on a second read. Standard library only, no network, no randomness — the same bytes on every run.

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
